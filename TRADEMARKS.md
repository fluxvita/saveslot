# Trademark policy

English · [简体中文](TRADEMARKS.zh-CN.md)

"SaveSlot", "saveslot" and the SaveSlot logo are trademarks of FluxVita. The [Apache-2.0 license](LICENSE) covers the code and the documentation; it does not grant rights to the trademarks (section 6 of the license). This policy says how you may use the name.

The goal is narrow: people should be able to tell whether something comes from the saveslot project. It is not meant to stop anyone from using, modifying, redistributing or hosting the software, which the license allows.

## What you may do without asking

- Refer to the project truthfully: "works with saveslot", "an MCP client for saveslot", "built on saveslot", "a fork of saveslot".
- Run saveslot, modified or not, for yourself or as a service for others, and say that it is based on saveslot.
- Write about saveslot in articles, talks, tutorials, courses and books.
- Name an integration, plugin or library so that it describes compatibility, for example `foo-for-saveslot`, as long as it is not presented as official.

## What needs written permission

- Using "SaveSlot" or a confusingly similar name as the name of your product, fork, hosted service or company, or in a domain name.
- Suggesting that something is official, endorsed by, or provided by the saveslot project when it is not.
- Using a modified version of the logo, or the logo as part of your own branding.

## Forks and modified versions

If you distribute a modified version, give it a different name. You may say that it is based on saveslot, and you must keep the license and notices as the license requires.

## Questions

Ask in the project's Discussions before you use the name in a way this page does not cover.
