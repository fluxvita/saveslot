# @fluxvita/saveslot-contract-core

**Internal package of saveslot.** It is published only because `@fluxvita/saveslot` depends on it, at the same
version. Its interface is not promised to be stable on its own and may change in any release. To use saveslot,
install `@fluxvita/saveslot`.

Data shapes shared by the kernel and the contract: value encoding, evidence, flags, intents, domain errors, event format types.
