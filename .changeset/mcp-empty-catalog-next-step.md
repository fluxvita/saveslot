`saveslot_catalog` with no slot to see now says what to do next, by what the connection may do: draft a schema to show the user and submit it once they agree; or have the user make a slot on the command line; or, for a connection limited to some slots, use one that sees every slot. It is the same sentence the server's instructions give, for hosts that do not pass those instructions to the model: before, the answer was only "No slots yet.", and an agent on such a host stopped there instead of offering to set up a table.
