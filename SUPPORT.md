# Getting help

- **Questions, ideas, "how do I …"**: [GitHub Discussions](https://github.com/fluxvita/saveslot/discussions).
  Search first; answers there help the next person too.
- **Something does not work as documented**: open an [issue](https://github.com/fluxvita/saveslot/issues/new/choose)
  with the bug template: the version (`saveslot --version`), what you ran, what you expected, what happened.
  `saveslot doctor` prints checks worth pasting.
- **A security issue**: never in public; see [`SECURITY.md`](SECURITY.md).
- **A conduct issue**: [opensource@fluxvita.com](mailto:opensource@fluxvita.com) ([Code of Conduct](CODE_OF_CONDUCT.md)).

The maintainers read Discussions and issues on working days and aim to answer a new one within a week.
saveslot is before 1.0 and comes with no support agreement.
